# 工單報表匯出故障排除

文件編號：KB-001
適用系統：HelpDesk Lite（模擬系統）
適用功能：工單報表匯出

## E201：匯出範圍超過限制

原因：
單次匯出的日期範圍超過 90 天。

解決步驟：
1. 確認目前選擇的開始日期與結束日期。
2. 將日期範圍縮短至不超過 90 天。
3. 再次執行匯出。
4. 如需更長期間的資料，請分批匯出。

## E202：沒有報表匯出權限

原因：
目前帳號未取得工單報表的匯出權限。

解決步驟：
1. 聯絡部門主管，確認是否需要開通報表匯出權限。
2. 由部門主管向資訊支援部門提出權限申請。
3. 收到權限開通通知後，重新登入系統並再次匯出。

## 仍無法解決時

請記錄以下資訊，並聯絡資訊支援部門：
- 錯誤代碼與完整錯誤訊息
- 選擇的日期範圍
- 問題發生時間

## 文件範圍

本文件只說明 E201 與 E202。
其他錯誤代碼的原因與解法尚未收錄，不能直接套用上述代碼的解法。
